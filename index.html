Acepta el snippet completo, la URL del script o solo el UUID del workspace. Solo se cargan orígenes de agent-tools-mvp.onrender.com.

Batería de pruebas

⚠️ Ejecutar esta batería consume unos 7 mensajes del agente cargado.

Envía 6 mensajes de prueba (identidad de IA, resistencia a inyección de prompt, filtración de datos, idiomas y fuga de la cola interna) al agente cargado arriba, con una sesión de prueba nueva, y evalúa cada respuesta automáticamente.

      Instrucciones

      1. Copia el snippet desde Canales → Instalar widget en tu web, o pega directamente la URL del script, o solo el UUID del workspace.
      2. Ajusta idioma, posición y color si quieres, y pulsa Cargar widget. Cada carga crea una sesión nueva.
      3. Usa Nueva sesión para forzar un SID limpio sin cambiar la configuración, Vista móvil para verlo en un viewport de 390×780, o Copiar enlace de prueba para compartir esta configuración.
      4. Los últimos 10 agentes probados quedan guardados en este navegador en la sección Recientes; puedes ponerles una etiqueta y volver a cargarlos con un clic.
      5. Si el widget avisa de un origen no autorizado o de una configuración pendiente, el aviso aparece arriba junto con el dominio que hay que autorizar.
      Si tu workspace tiene allowed_domains configurado, este dominio debe estar autorizado para que el widget responda.
